# Vigio — version de test

Page de démonstration de Vigio, observatoire citoyen de l’opinion publique : accueil et question du jour,
exploration, vote en deux étapes, résultats et évolution, profil, coulisses de la veille d’actualité.

- **Toutes les données sont fictives** (consultations, participations, résultats, propositions d’actualité).
- Fonctionne entièrement dans le navigateur : aucun compte, aucun serveur ; les votes restent sur l’appareil.
- Animations désactivées automatiquement si l’appareil demande moins d’animations (réglage d’accessibilité).
- Photos réelles des sujets, sous licence libre (Wikimedia Commons) : auteur et licence sous chaque photo et dans « À propos ». Les résultats affichés restent fictifs.
- Logo provisoire, en attente des fichiers officiels.
