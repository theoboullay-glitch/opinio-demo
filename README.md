# Opinio — version de test

Page de démonstration d’Opinio, observatoire citoyen de l’opinion publique : accueil et question du jour,
exploration, vote en deux étapes, résultats et évolution, profil, coulisses de la veille d’actualité.

- **Toutes les données sont fictives** (consultations, participations, résultats, propositions d’actualité).
- Fonctionne entièrement dans le navigateur : aucun compte, aucun serveur ; les votes restent sur l’appareil.
- Logo provisoire, en attente des fichiers officiels.
